# Recursos Visuales

Carpeta para almacenar las imágenes de las turbinas y el logo de la empresa.

Qué incluir:
- Imágenes de las turbinas (fotografías, renders).
- Logo de la empresa en formatos vectoriales y raster (preferible SVG para logo, PNG/JPEG para fotos).

Convenciones recomendadas de nombre de archivo:
- turbina_001.jpg, turbina_002.jpg, ...
- logo_empresa.svg
- logo_empresa_color.png

Formatos y tamaños recomendados:
- Logo: preferible SVG (vector). Además se puede incluir PNG a 512×512 para usos web.
- Fotografías: JPEG o PNG. Optimizar para web (p. ej. < 2 MB) cuando sea posible.

Cómo subir imágenes:
- Desde la interfaz web de GitHub: "Add file" → "Upload files" dentro de esta carpeta.
- Usando git localmente: añadir los archivos a `Recursos Visuales/` y hacer commit/push.

Notas:
- Evitar incluir imágenes extremadamente grandes sin compresión.
- Si prefieres que gestione la subida de imágenes o que cree subcarpetas (por ejemplo `turbinas/` y `logo/`), dime y lo hago.
